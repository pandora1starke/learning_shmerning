# Payclock watch face test builds

Install payclock-watch-v1.6.apk over the existing app with adb install -r, then install payclock-face-v1.0.apk. Long-press the watch face, choose Add watch face, and select Payclock Face. If needed, edit its complications and choose Payclock earnings and Payclock time worked. Tap either value to open the tracker. Earnings request refresh every five minutes and after session changes; actual timing is controlled by Wear OS. The face follows the watch system clock format, with its own color selection. APKs are debug-signed test builds, not Play Store releases. Face XML and APK structure were validated, but real-watch selection, rendering, refresh and tap behavior still require testing.
