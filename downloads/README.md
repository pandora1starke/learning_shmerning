# Payclock test builds

Install companion app 1.8 and Payclock Face 1.1 using adb install -r. The face has a small dots button that opens app settings. Its background, clock, earnings, timer and options follow the app color scheme; changes request Wear OS updates rather than using a separate face color selector. If the old face configuration persists, re-add Payclock Face or select Payclock theme, Payclock earnings, Payclock time worked and Payclock options in the corresponding slots. Auto-pause at shift end remains supported. Builds, WFF validation, palette consistency and calculations passed; real-watch button, theme refresh and rendering checks are still required. Debug-signed test builds, not Play Store releases.
