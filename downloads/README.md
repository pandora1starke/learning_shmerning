# Payclock test builds

Companion app 1.7 automatically pauses earnings and worked time at the selected shift end, including when the app is closed. Late alarm delivery or reopening reconciles earnings to the saved deadline, not the wake time. Notification permission affects the alert only. Exact-alarm access improves notification timing. Compatible faces receive a future paused-state timeline. Use adb install -r to keep the session and preferences; Payclock Face 1.0 does not need reinstalling. Device alarm delivery and watch-face rendering still require real-watch testing. Debug-signed APKs, not Play Store releases.
